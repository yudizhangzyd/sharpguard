# Superseded artifacts

Nothing in the paper reads any file in this directory. It exists so that the
release keeps an audit trail instead of quietly overwriting history. The
authoritative artifacts are `results_v2/canonical_runs/` (one pinned run per
model) plus `results_v2/derived_metrics.json` (everything the manuscript
quotes, regenerated by `scripts/derive_metrics.py` and checked by
`scripts/verify_paper_numbers.py`).

These files were moved here because an R1 reviewer correctly observed that
`results_v2/` contained artifacts contradicting the submitted numbers, which
makes the whole release untrustworthy regardless of the science.

## Withdrawn N=1 cross-corpus pilot

| file | why superseded | replaced by |
|---|---|---|
| `bcz.json` | `n_samples_used = 1`; the paper claims an N=30 sweep | `canonical_runs/cross_corpus_bcz_n30.json` |
| `bridge_v2.json` | `n_samples_used = 1` | `canonical_runs/cross_corpus_bridge_v2_n30.json` |
| `fractal.json` | `n_samples_used = 1` | `canonical_runs/cross_corpus_fractal_n30.json` |

The N=1 pilot is withdrawn, not merely superseded: a single sample supports no
variance estimate and the paper no longer cites it anywhere.
